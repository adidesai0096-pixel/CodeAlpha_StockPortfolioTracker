# Stock Portfolio Tracker

## About the Project
A Python-based stock portfolio tracker developed as part of my CodeAlpha Python Programming Internship.

## Features
- Add stocks to the portfolio
- View stock holdings
- Calculate total investment
- Calculate profit or loss using manually entered current prices
- Remove stocks from the portfolio
- Save portfolio data using JSON

## Technologies Used
- Python
- JSON
- File Handling

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the command:

   python Stock_Portfolio_Tracker.py

## Disclaimer
This is an educational project. Stock prices are entered manually and are not live market prices.
